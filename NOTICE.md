## Set B session text

The 18 Set B sessions come from the Hugging Face dataset `MaxDevv/real-pi-coding-agent-traces-sessions`, which collects public Pi coding agent sessions. Each session stays under the licence of its source. All 18 used here come from MIT licensed sources: `woxQAQ/pi-web`, `thomasmustier/pi-for-excel-sessions`, `thomasmustier/pi-extensions-sessions`, `thomasmustier/pi-mono-sessions` and `thomasmustier/economist-tui-sessions`. The source and SHA-256 of each session are recorded on its item under `label.paper`. See each source repository for its copyright notice.

The items contain a rendered and shortened form of those sessions.
